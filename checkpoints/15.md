# Checkpoint 15: Tool Use and Tool Calling: Extensible Execution Engines

## Exercise 15.1: Register typed tools

- **Description**: Maintain a name-to-(schema,handler) registry. Reject missing, invalid or duplicate names and noncallable handlers.
- **Objective**: Implement `register(registry,name,schema,handler)`.
- **Solution Code**:

```python
def register(registry, name, schema, handler):
    if not name.isidentifier() or name in registry or not callable(handler):
        raise ValueError("invalid or repeated tool")
    registry[name] = (schema, handler)
```

## Exercise 15.2: Validate arguments before dispatch

- **Description**: Look up a registered tool, parse its JSON through a strict Pydantic schema, and invoke its handler using validated keyword arguments.
- **Objective**: Implement `dispatch(registry,name,raw)`.
- **Solution Code**:

```python
def dispatch(registry, name, raw):
    schema, handler = registry[name]
    args = schema.model_validate_json(raw, strict=True)
    return handler(**args.model_dump())
```

## Exercise 15.3: Authorize tool execution

- **Description**: Require all policy scopes for a registered tool. Unknown names and insufficient scopes must fail before handler execution.
- **Objective**: Implement `authorized(name,policies,granted,invoke)`.
- **Solution Code**:

```python
def authorized(name, policies, granted, invoke):
    if name not in policies or not set(policies[name]).issubset(granted):
        raise PermissionError(name)
    return invoke()
```

## Exercise 15.4: Enforce async tool deadlines

- **Description**: Execute a cooperative asynchronous tool within a positive deadline. Propagate timeouts and caller cancellation.
- **Objective**: Implement `timed_call(tool,args,seconds)`.
- **Solution Code**:

```python
async def timed_call(tool, args, seconds):
    import asyncio

    if seconds <= 0:
        raise ValueError("positive deadline required")
    async with asyncio.timeout(seconds):
        return await tool(**args)
```

## Exercise 15.5: Limit concurrent tool calls

- **Description**: Run asynchronous call factories under a concurrency cap and return results in input order. Cancel sibling work on failure.
- **Objective**: Implement `parallel_tools(calls,limit)`.
- **Solution Code**:

```python
async def parallel_tools(calls, limit):
    import asyncio

    if limit < 1:
        raise ValueError("positive concurrency required")
    semaphore = asyncio.Semaphore(limit)

    async def run(call):
        async with semaphore:
            return await call()

    async with asyncio.TaskGroup() as group:
        tasks = [group.create_task(run(call)) for call in calls]
    return [task.result() for task in tasks]
```

## Exercise 15.6: Bound tool response size

- **Description**: Serialize finite JSON results within a UTF-8 byte ceiling. Reject oversized payloads without cutting a JSON token or Unicode character.
- **Objective**: Implement `bounded_json(result,limit)`.
- **Solution Code**:

```python
def bounded_json(result, limit):
    import json

    text = json.dumps(
        result, ensure_ascii=False, allow_nan=False, separators=(",", ":")
    )
    if len(text.encode()) > limit:
        raise ValueError("tool output too large")
    return text
```

## Exercise 15.7: Detect repeated tool loops

- **Description**: Detect when the most recent N tool requests have the same name and canonically equivalent JSON parameters.
- **Objective**: Implement `looping(requests,n)`.
- **Solution Code**:

```python
def looping(requests, n):
    import json

    if n < 2:
        raise ValueError("repeat threshold must exceed one")
    recent = requests[-n:]
    keys = [
        json.dumps([name, args], sort_keys=True, allow_nan=False)
        for name, args in recent
    ]
    return len(keys) == n and len(set(keys)) == 1
```

## Exercise 15.8: Replay successful tool calls

- **Description**: For a sequential session, reuse a completed result by call ID and canonical arguments. Reject ID reuse with different arguments. Cache only successful executions.
- **Objective**: Implement `replay(cache,call_id,name,args,invoke)`.
- **Solution Code**:

```python
def replay(cache, call_id, name, args, invoke):
    import json

    key = json.dumps([name, args], sort_keys=True, allow_nan=False)
    if call_id in cache:
        old, value = cache[call_id]
        if old != key:
            raise ValueError("conflicting call ID")
        return value
    value = invoke()
    cache[call_id] = (key, value)
    return value
```

## Exercise 15.9: Expose safe tool errors

- **Description**: Map known validation and timeout failures to stable machine-readable error codes without leaking raw exception text. Propagate unexpected failures.
- **Objective**: Implement `tool_result(invoke)`.
- **Solution Code**:

```python
def tool_result(invoke):
    try:
        return {"ok": True, "value": invoke()}
    except TimeoutError:
        return {"ok": False, "error": "timeout"}
    except ValueError:
        return {"ok": False, "error": "invalid_arguments"}
```

## Exercise 15.10: Audit an execution

- **Description**: Measure elapsed monotonic time and emit a structured success/failure event including call ID and tool name. Never include tool arguments or output.
- **Objective**: Implement `audited(call_id,name,invoke,clock,emit)`.
- **Solution Code**:

```python
def audited(call_id, name, invoke, clock, emit):
    start = clock()
    status = "error"
    try:
        result = invoke()
        status = "ok"
        return result
    finally:
        emit(
            {
                "call_id": call_id,
                "tool": name,
                "status": status,
                "elapsed": clock() - start,
            }
        )
```
