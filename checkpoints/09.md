## Exercise 09.1: Compute attention logits

- **Description**: Return batched query-key products scaled by the square root of the head dimension.
- **Objective**: Implement `attention_logits(q,k)`.
- **Solution Code**:

```python
import math


def attention_logits(q, k):
    return q @ k.transpose(-2, -1) / math.sqrt(q.shape[-1])
```

## Exercise 09.2: Masked softmax

- **Description**: Return probabilities over allowed keys along the last dimension. Fully masked rows must be zero and have finite gradients.
- **Objective**: Implement `masked_softmax(scores, allowed)`.
- **Solution Code**:

```python
import torch


def masked_softmax(scores, allowed):
    masked = scores.masked_fill(~allowed, float("-inf"))
    has_keys = allowed.any(dim=-1, keepdim=True)
    safe = torch.where(has_keys, masked, 0.0)
    return torch.softmax(safe, dim=-1).masked_fill(~allowed, 0.0)
```

## Exercise 09.3: Causal mask with past context

- **Description**: Build a boolean query-by-key mask for a suffix of new tokens following a cached prefix.
- **Objective**: Implement `causal_mask(length, past=0, device=None)`.
- **Solution Code**:

```python
import torch


def causal_mask(length, past=0, device=None):
    positions = torch.arange(length, device=device) + past
    keys = torch.arange(past + length, device=device)
    return keys[None, :] <= positions[:, None]
```

## Exercise 09.4: Split attention heads

- **Description**: Transform batch-by-time-by-model tensors into batch-by-head-by-time-by-head_dim. Reject indivisible widths.
- **Objective**: Implement `split_heads(x, heads)`.
- **Solution Code**:

```python
def split_heads(x, heads):
    b, t, d = x.shape
    if heads <= 0 or d % heads:
        raise ValueError("incompatible heads")
    return x.reshape(b, t, heads, d // heads).transpose(1, 2)
```

## Exercise 09.5: Reassemble projected heads

- **Description**: Restore model width by concatenating heads at each position, accepting noncontiguous tensors.
- **Objective**: Implement `join_heads(x)`.
- **Solution Code**:

```python
def join_heads(x):
    b, h, t, d = x.shape
    return x.transpose(1, 2).reshape(b, t, h * d)
```

## Exercise 09.6: Scaled dot-product attention

- **Description**: Compute softmax attention weights and weighted values from Q, K and V, supporting different query and key lengths.
- **Objective**: Implement `attend(q,k,v)`.
- **Solution Code**:

```python
import math


def attend(q, k, v):
    logits = q @ k.transpose(-2, -1) / math.sqrt(q.shape[-1])
    weights = logits.softmax(dim=-1)
    return weights @ v, weights
```

## Exercise 09.7: Multi-head causal self-attention

- **Description**: Project Q/K/V jointly, apply causal attention independently per head, combine heads and project the output.
- **Objective**: Implement `CausalAttention(nn.Module)`.
- **Solution Code**:

```python
import math
import torch
from torch import nn


class CausalAttention(nn.Module):
    def __init__(self, width, heads):
        super().__init__()
        if heads < 1 or width % heads:
            raise ValueError("incompatible heads")
        self.heads = heads
        self.qkv = nn.Linear(width, 3 * width)
        self.output = nn.Linear(width, width)

    def forward(self, x):
        b, t, d = x.shape
        q, k, v = (
            a.reshape(b, t, self.heads, d // self.heads).transpose(1, 2)
            for a in self.qkv(x).chunk(3, dim=-1)
        )
        logits = q @ k.transpose(-2, -1) / math.sqrt(d // self.heads)
        future = torch.ones(t, t, dtype=torch.bool, device=x.device).triu(1)
        weights = logits.masked_fill(future, float("-inf")).softmax(-1)
        return self.output((weights @ v).transpose(1, 2).reshape(b, t, d))
```

## Exercise 09.8: Append KV states

- **Description**: Update a per-layer key/value cache along the time axis. Support an empty cache and reject mismatched new time lengths.
- **Objective**: Implement `append_kv(previous,k,v)`.
- **Solution Code**:

```python
import torch


def append_kv(previous, k, v):
    if k.shape[-2] != v.shape[-2]:
        raise ValueError("unaligned time axes")
    if previous is None:
        return k, v
    pk, pv = previous
    return torch.cat([pk, k], dim=-2), torch.cat([pv, v], dim=-2)
```

## Exercise 09.9: Sinusoidal positional features

- **Description**: Generate alternating sine and cosine features using the original Transformer frequency schedule. Handle odd widths.
- **Objective**: Implement `positions(length,width)`.
- **Solution Code**:

```python
import math
import torch


def positions(length, width):
    if width < 1:
        raise ValueError("positive width required")
    rate = torch.exp(-math.log(10000) * torch.arange(0, width, 2) / width)
    phase = torch.arange(length)[:, None] * rate
    out = torch.empty(length, width)
    out[:, 0::2] = phase.sin()
    out[:, 1::2] = phase[:, : width // 2].cos()
    return out
```

## Exercise 09.10: Pre-norm Transformer block

- **Description**: Compose injected self-attention with two residual branches, pre-normalization and a GELU feed-forward expansion.
- **Objective**: Implement `Block(nn.Module)`.
- **Solution Code**:

```python
from torch import nn


class Block(nn.Module):
    def __init__(self, width, attention):
        super().__init__()
        self.attention = attention
        self.first = nn.LayerNorm(width)
        self.second = nn.LayerNorm(width)
        self.ff = nn.Sequential(
            nn.Linear(width, 4 * width), nn.GELU(), nn.Linear(4 * width, width)
        )

    def forward(self, x):
        x = x + self.attention(self.first(x))
        return x + self.ff(self.second(x))
```
