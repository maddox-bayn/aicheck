## Exercise 06.1: Configurable classifier

- **Description**: Build an MLP with a hidden ReLU, dropout and unnormalized class logits.
- **Objective**: Implement `mlp(inputs, hidden, classes, dropout=.1)`.
- **Solution Code**:

```python
from torch import nn


def mlp(inputs, hidden, classes, dropout=0.1):
    return nn.Sequential(
        nn.Linear(inputs, hidden),
        nn.ReLU(),
        nn.Dropout(dropout),
        nn.Linear(hidden, classes),
    )
```

## Exercise 06.2: Residual dense block

- **Description**: Apply a two-layer width-preserving branch with an internal ReLU, added to the identity shortcut.
- **Objective**: Implement `Residual(nn.Module)`.
- **Solution Code**:

```python
from torch import nn


class Residual(nn.Module):
    def __init__(self, width):
        super().__init__()
        self.branch = nn.Sequential(
            nn.Linear(width, width), nn.ReLU(), nn.Linear(width, width)
        )

    def forward(self, x):
        return x + self.branch(x)
```

## Exercise 06.3: Convolutional feature extractor

- **Description**: Build a 3x3 convolution, batch normalization and ReLU block that preserves spatial dimensions.
- **Objective**: Implement `conv_block(inputs, outputs)`.
- **Solution Code**:

```python
from torch import nn


def conv_block(inputs, outputs):
    return nn.Sequential(
        nn.Conv2d(inputs, outputs, 3, padding=1, bias=False),
        nn.BatchNorm2d(outputs),
        nn.ReLU(),
    )
```

## Exercise 06.4: Resolution-independent CNN

- **Description**: Build a small image classifier that accepts variable spatial resolutions via global average pooling.
- **Objective**: Implement `image_net(channels, classes)`.
- **Solution Code**:

```python
from torch import nn


def image_net(channels, classes):
    return nn.Sequential(
        nn.Conv2d(channels, 16, 3, padding=1),
        nn.ReLU(),
        nn.AdaptiveAvgPool2d(1),
        nn.Flatten(),
        nn.Linear(16, classes),
    )
```

## Exercise 06.5: Depthwise separable convolution

- **Description**: Implement channel-wise spatial filtering followed by pointwise channel mixing. Preserve spatial size.
- **Objective**: Implement `separable(inputs, outputs)`.
- **Solution Code**:

```python
from torch import nn


def separable(inputs, outputs):
    return nn.Sequential(
        nn.Conv2d(inputs, inputs, 3, padding=1, groups=inputs, bias=False),
        nn.Conv2d(inputs, outputs, 1, bias=False),
    )
```

## Exercise 06.7: Class-balanced loss

- **Description**: Construct weighted cross entropy using inverse training class counts. Reject absent classes.
- **Objective**: Implement `balanced_loss(counts)`.
- **Solution Code**:

```python
import torch
from torch import nn


def balanced_loss(counts):
    counts = torch.as_tensor(counts, dtype=torch.float32)
    if counts.ndim != 1 or not torch.all(counts > 0):
        raise ValueError("each class needs observations")
    return nn.CrossEntropyLoss(weight=counts.sum() / (len(counts) * counts))
```

## Exercise 06.8: Evaluate without gradient tracking

- **Description**: Compute sample-weighted accuracy over batches. Restore the model's previous training mode even on failure.
- **Objective**: Implement `accuracy(model, batches)`.
- **Solution Code**:

```python
import torch


def accuracy(model, batches):
    mode = model.training
    correct = total = 0
    try:
        model.eval()
        with torch.inference_mode():
            for x, y in batches:
                correct += (model(x).argmax(1) == y).sum().item()
                total += y.numel()
        if not total:
            raise ValueError("no labels")
        return correct / total
    finally:
        model.train(mode)
```

## Exercise 06.9: Best-weight checkpoint

- **Description**: Create an independent CPU state dictionary suitable for restoring a model after early stopping.
- **Objective**: Implement `best_state(model)`.
- **Solution Code**:

```python
def best_state(model):
    return {
        key: value.detach().cpu().clone() for key, value in model.state_dict().items()
    }
```

## Exercise 06.10: Train a classifier for one epoch

- **Description**: Run optimizer updates over labeled batches and return mean cross entropy weighted by batch size.
- **Objective**: Implement `train_epoch(model, batches, optimizer)`.
- **Solution Code**:

```python
from torch import nn


def train_epoch(model, batches, optimizer):
    model.train()
    total = count = 0
    for x, y in batches:
        optimizer.zero_grad(set_to_none=True)
        loss = nn.functional.cross_entropy(model(x), y)
        loss.backward()
        optimizer.step()
        total += loss.detach().item() * len(y)
        count += len(y)
    if not count:
        raise ValueError("empty epoch")
    return total / count
```
