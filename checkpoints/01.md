## Exercise 01.1: Normalize embedding rows

- **Description**: Normalize each row to unit L2 length, keeping zero vectors zero.
- **Objective**: Implement `unit_rows(x)`.
- **Solution Code**:

```python
import numpy as np


def unit_rows(x):
    x = np.asarray(x, dtype=float)
    lengths = np.linalg.norm(x, axis=1, keepdims=True)
    return np.divide(x, lengths, out=np.zeros_like(x), where=lengths != 0)
```

## Exercise 01.2: Pairwise squared distances

- **Description**: Compute all query-to-index squared Euclidean distances using matrix products. Clamp roundoff below zero.
- **Objective**: Implement `squared_distances(q, index)`.
- **Solution Code**:

```python
import numpy as np


def squared_distances(q, index):
    q, index = np.asarray(q, float), np.asarray(index, float)
    distances = (q * q).sum(1)[:, None] + (index * index).sum(1) - 2 * q @ index.T
    return np.maximum(distances, 0)
```

## Exercise 01.3: Stable row softmax

- **Description**: Produce class probabilities for finite logit matrices even when logits exceed 1000.
- **Objective**: Implement `softmax(x)`.
- **Solution Code**:

```python
import numpy as np


def softmax(x):
    x = np.asarray(x, float)
    weights = np.exp(x - x.max(axis=1, keepdims=True))
    return weights / weights.sum(axis=1, keepdims=True)
```

## Exercise 01.4: Masked channel mean

- **Description**: Average valid timesteps in a batch of feature sequences. Emit zero for empty sequences and ignore masked NaNs.
- **Objective**: Implement `masked_mean(x, mask)`.
- **Solution Code**:

```python
import numpy as np


def masked_mean(x, mask):
    mask = np.asarray(mask, bool)[..., None]
    total = np.where(mask, x, 0).sum(axis=1)
    return total / np.maximum(mask.sum(axis=1), 1)
```

## Exercise 01.5: Whiten correlated features

- **Description**: Center observations and whiten using the Cholesky factor of the sample covariance plus positive diagonal jitter.
- **Objective**: Implement `whiten(x, jitter=1e-6)`.
- **Solution Code**:

```python
import numpy as np


def whiten(x, jitter=1e-6):
    x = np.asarray(x, float)
    if len(x) < 2 or jitter <= 0:
        raise ValueError("need two observations and positive jitter")
    centered = x - x.mean(axis=0)
    covariance = centered.T @ centered / (len(x) - 1)
    factor = np.linalg.cholesky(covariance + jitter * np.eye(x.shape[1]))
    return np.linalg.solve(factor, centered.T).T
```

## Exercise 01.6: Ridge without a matrix inverse

- **Description**: Fit coefficients without an intercept on feature matrix X using positive L2 regularization and a linear solve.
- **Objective**: Implement `ridge(x, y, penalty)`.
- **Solution Code**:

```python
import numpy as np


def ridge(x, y, penalty):
    x = np.asarray(x, float)
    if penalty <= 0:
        raise ValueError("positive penalty required")
    return np.linalg.solve(x.T @ x + penalty * np.eye(x.shape[1]), x.T @ y)
```

## Exercise 01.7: Truncated SVD reconstruction

- **Description**: Return the best rank-k reconstruction in Frobenius norm, allowing rank zero.
- **Objective**: Implement `reconstruct(x, k)`.
- **Solution Code**:

```python
import numpy as np


def reconstruct(x, k):
    u, s, vt = np.linalg.svd(x, full_matrices=False)
    if not 0 <= k <= len(s):
        raise ValueError("rank outside matrix dimensions")
    return (u[:, :k] * s[:k]) @ vt[:k]
```

## Exercise 01.8: Batched quadratic scores

- **Description**: Compute one Mahalanobis squared score per sample against a supplied mean and precision matrix.
- **Objective**: Implement `quadratic_scores(x, mean, precision)`.
- **Solution Code**:

```python
import numpy as np


def quadratic_scores(x, mean, precision):
    delta = np.asarray(x, float) - mean
    return np.einsum("ni,ij,nj->n", delta, precision, delta)
```

## Exercise 01.9: Scatter repeated feature IDs

- **Description**: Accumulate repeated feature contributions into a fixed-width vector. Reject out-of-range indices.
- **Objective**: Implement `scatter_sum(ids, weights, width)`.
- **Solution Code**:

```python
import numpy as np


def scatter_sum(ids, weights, width):
    ids = np.asarray(ids, dtype=np.intp)
    if np.any((ids < 0) | (ids >= width)):
        raise ValueError("feature id outside vocabulary")
    out = np.zeros(width)
    np.add.at(out, ids, weights)
    return out
```

## Exercise 01.10: Streaming covariance merge

- **Description**: Merge two nonempty batches represented as (count, mean vector, unnormalized centered scatter matrix), without raw records.
- **Objective**: Implement `merge_moments(a, b)`.
- **Solution Code**:

```python
import numpy as np


def merge_moments(a, b):
    na, ma, sa = a
    nb, mb, sb = b
    n = na + nb
    delta = np.asarray(mb) - ma
    return n, ma + delta * nb / n, sa + sb + np.outer(delta, delta) * na * nb / n
```
