## Exercise 02.1: Validate incoming observations

- **Description**: Define a strict Pydantic v2 record with a nonempty sensor ID and a finite floating reading. Forbid unknown fields.
- **Objective**: Implement `Observation(BaseModel)`.
- **Solution Code**:

```python
from pydantic import BaseModel, ConfigDict, Field, FiniteFloat


class Observation(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    sensor: str = Field(min_length=1)
    reading: FiniteFloat
```

## Exercise 02.2: Quarantine invalid rows

- **Description**: Apply an injected Pydantic model to each mapping. Return valid serialized records and indexed validation errors.
- **Objective**: Implement `quarantine(rows, schema)`.
- **Solution Code**:

```python
from pydantic import ValidationError


def quarantine(rows, schema):
    accepted, rejected = [], []
    for index, row in enumerate(rows):
        try:
            accepted.append(schema.model_validate(row).model_dump())
        except ValidationError as exc:
            rejected.append((index, exc.errors(include_input=False)))
    return accepted, rejected
```

## Exercise 02.3: Canonical timestamps

- **Description**: Parse mixed ISO timestamps to UTC. Preserve the Series index and coerce invalid input to NaT.
- **Objective**: Implement `utc_times(series)`.
- **Solution Code**:

```python
import pandas as pd


def utc_times(series):
    return pd.to_datetime(series, utc=True, errors="coerce", format="mixed")
```

## Exercise 02.5: Enforce dimension cardinality

- **Description**: Left-join a fact table to a dimension on id. Preserve unmatched rows and reject duplicate dimension keys.
- **Objective**: Implement `enrich(facts, dimension)`.
- **Solution Code**:

```python
def enrich(facts, dimension):
    return facts.merge(dimension, on="id", how="left", validate="many_to_one")
```

## Exercise 02.6: Leakage-safe lag feature

- **Description**: For each device in chronological order, attach the preceding reading. Restore input row order even with duplicate index labels.
- **Objective**: Implement `add_lag(frame)`.
- **Solution Code**:

```python
def add_lag(frame):
    ordered = frame.assign(_pos=range(len(frame))).sort_values(
        ["device", "time", "_pos"]
    )
    ordered["lag"] = ordered.groupby("device")["value"].shift()
    return ordered.sort_values("_pos").drop(columns="_pos")
```

## Exercise 02.7: Resample event volumes

- **Description**: Count rows per UTC hour from a DatetimeIndex, returning explicit zero counts between active hours.
- **Objective**: Implement `hourly_counts(frame)`.
- **Solution Code**:

```python
def hourly_counts(frame):
    if frame.index.tz is None:
        raise ValueError("timezone required")
    return frame.tz_convert("UTC").resample("h").size()
```

## Exercise 02.8: Training-only imputation

- **Description**: Fill missing numeric feature values using training column medians. Reject all-missing training features and preserve inference column order.
- **Objective**: Implement `impute(train, incoming)`.
- **Solution Code**:

```python
def impute(train, incoming):
    medians = train[incoming.columns].median()
    if medians.isna().any():
        raise ValueError("missing training median")
    return incoming.fillna(medians)
```

## Exercise 02.9: Bounded-memory group totals

- **Description**: Combine nonempty or empty iterators of DataFrame chunks into totals by string account, sorted by account.
- **Objective**: Implement `chunk_totals(chunks)`.
- **Solution Code**:

```python
def chunk_totals(chunks):
    totals = {}
    for chunk in chunks:
        for account, value in chunk.groupby("account")["amount"].sum().items():
            totals[account] = totals.get(account, 0) + value
    return dict(sorted(totals.items()))
```

## Exercise 02.10: Point-in-time feature lookup

- **Description**: Join events to the most recent same-device feature available at or before each event. Return rows in original order.
- **Objective**: Implement `point_in_time(events, features)`.
- **Solution Code**:

```python
import pandas as pd


def point_in_time(events, features):
    left = events.assign(_pos=range(len(events))).sort_values("time")
    joined = pd.merge_asof(
        left, features.sort_values("time"), on="time", by="device", direction="backward"
    )
    return joined.sort_values("_pos").drop(columns="_pos")
```
