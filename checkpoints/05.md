## Exercise 05.1: Differentiate squared error

- **Description**: Return mean squared prediction loss and its gradient with respect to a linear weight vector.
- **Objective**: Implement `mse_gradient(x, y, w)`.
- **Solution Code**:

```python
import numpy as np


def mse_gradient(x, y, w):
    residual = np.asarray(x) @ w - y
    return np.mean(residual**2), 2 * np.asarray(x).T @ residual / len(y)
```

## Exercise 05.2: Stable binary cross entropy

- **Description**: Compute mean binary cross entropy from finite logits without overflowing either tail.
- **Objective**: Implement `logistic_loss(logits, labels)`.
- **Solution Code**:

```python
import numpy as np


def logistic_loss(logits, labels):
    z = np.asarray(logits, float)
    return np.mean(np.logaddexp(0, np.where(np.asarray(labels) == 1, -z, z)))
```

## Exercise 05.3: Huber influence

- **Description**: Return per-residual Huber losses and derivatives for a positive transition width.
- **Objective**: Implement `huber(residual, delta)`.
- **Solution Code**:

```python
import numpy as np


def huber(residual, delta):
    if delta <= 0:
        raise ValueError("positive delta required")
    r = np.asarray(residual, float)
    small = np.abs(r) <= delta
    return np.where(small, r * r / 2, delta * (np.abs(r) - delta / 2)), np.clip(
        r, -delta, delta
    )
```

## Exercise 05.4: Finite-difference gradient check

- **Description**: Approximate every derivative of a scalar function by centered differences without mutating input weights.
- **Objective**: Implement `numerical_gradient(fn, w, eps=1e-5)`.
- **Solution Code**:

```python
import numpy as np


def numerical_gradient(fn, w, eps=1e-5):
    w = np.asarray(w, float)
    if eps <= 0:
        raise ValueError("positive perturbation required")
    result = np.empty_like(w)
    for index in np.ndindex(w.shape):
        step = np.zeros_like(w)
        step[index] = eps
        result[index] = (fn(w + step) - fn(w - step)) / (2 * eps)
    return result
```

## Exercise 05.5: Full-batch descent

- **Description**: Minimize a differentiable objective using a gradient callback, step budget, and gradient-norm stopping condition.
- **Objective**: Implement `descend(gradient, start, rate, steps, tolerance)`.
- **Solution Code**:

```python
import numpy as np


def descend(gradient, start, rate, steps, tolerance):
    w = np.array(start, dtype=float, copy=True)
    if rate <= 0 or steps < 0 or tolerance < 0:
        raise ValueError("invalid schedule")
    for _ in range(steps):
        g = gradient(w)
        if np.linalg.norm(g) <= tolerance:
            break
        w -= rate * g
    return w
```

## Exercise 05.6: Momentum update

- **Description**: Compute classical momentum velocity and the new weights. Preserve caller-owned inputs.
- **Objective**: Implement `momentum(w, velocity, grad, rate, beta)`.
- **Solution Code**:

```python
import numpy as np


def momentum(w, velocity, grad, rate, beta):
    v = beta * np.asarray(velocity) + grad
    return np.asarray(w) - rate * v, v
```

## Exercise 05.7: Adam bias correction

- **Description**: Perform one Adam update for a one-based step number. Return new weights and both uncorrected moments.
- **Objective**: Implement `adam(w, g, m, v, t, rate=.001, b1=.9, b2=.999, eps=1e-8)`.
- **Solution Code**:

```python
import numpy as np


def adam(w, g, m, v, t, rate=0.001, b1=0.9, b2=0.999, eps=1e-8):
    if t < 1 or not 0 <= b1 < 1 or not 0 <= b2 < 1 or eps <= 0:
        raise ValueError("invalid Adam parameters")
    g = np.asarray(g)
    m = b1 * m + (1 - b1) * g
    v = b2 * v + (1 - b2) * g * g
    update = (m / (1 - b1**t)) / (np.sqrt(v / (1 - b2**t)) + eps)
    return w - rate * update, m, v
```

## Exercise 05.8: Multiclass cross-entropy gradient

- **Description**: Return mean softmax cross entropy and its gradient for integer class labels. Use shifted log-sum-exp.
- **Objective**: Implement `multiclass(z, labels)`.
- **Solution Code**:

```python
import numpy as np


def multiclass(z, labels):
    z = np.asarray(z, float)
    shifted = z - z.max(axis=1, keepdims=True)
    logp = shifted - np.log(np.exp(shifted).sum(axis=1, keepdims=True))
    rows = np.arange(len(z))
    loss = -logp[rows, labels].mean()
    grad = np.exp(logp)
    grad[rows, labels] -= 1
    return loss, grad / len(z)
```

## Exercise 05.9: Backpropagate through a hidden layer

- **Description**: For a bias-free tanh MLP and scalar sum of output logits, return gradients for both weight matrices.
- **Objective**: Implement `mlp_backward(x, w1, w2)`.
- **Solution Code**:

```python
import numpy as np


def mlp_backward(x, w1, w2):
    hidden = np.tanh(x @ w1)
    upstream = np.ones_like(hidden @ w2)
    return x.T @ ((upstream @ w2.T) * (1 - hidden**2)), hidden.T @ upstream
```

## Exercise 05.10: Backtracking line search

- **Description**: Halve a trial gradient-descent step until it satisfies Armijo decrease. Raise if the trial budget is exhausted.
- **Objective**: Implement `backtrack(fn, w, grad, initial=1., trials=30)`.
- **Solution Code**:

```python
import numpy as np


def backtrack(fn, w, grad, initial=1.0, trials=30):
    if initial <= 0:
        raise ValueError("positive initial step required")
    base = fn(w)
    step = initial
    for _ in range(trials):
        candidate = w - step * grad
        if fn(candidate) <= base - 1e-4 * step * np.sum(grad**2):
            return candidate, step
        step *= 0.5
    raise RuntimeError("no acceptable step")
```
