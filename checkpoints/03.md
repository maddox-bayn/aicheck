## Exercise 03.1: Device-aware batching

- **Description**: Stack equal-shaped tensors on a requested device while preserving dtype and gradients.
- **Objective**: Implement `batch(items, device)`.
- **Solution Code**:

```python
import torch


def batch(items, device):
    return torch.stack(items).to(device)
```

## Exercise 03.2: Gather class scores

- **Description**: Select one score per example using integer class labels and keep the result differentiable.
- **Objective**: Implement `class_scores(logits, labels)`.
- **Solution Code**:

```python
def class_scores(logits, labels):
    return logits.gather(1, labels.long().reshape(-1, 1)).squeeze(1)
```

## Exercise 03.3: Vector-Jacobian product

- **Description**: Return the vector-Jacobian product of a tensor-valued callable without populating parameter .grad fields.
- **Objective**: Implement `vjp(fn, x, vector)`.
- **Solution Code**:

```python
import torch


def vjp(fn, x, vector):
    output = fn(x)
    return torch.autograd.grad(output, x, grad_outputs=vector)[0]
```

## Exercise 03.4: Hessian-vector product

- **Description**: Compute a scalar loss Hessian times a vector using two autograd passes, without materializing the Hessian.
- **Objective**: Implement `hvp(loss, x, vector)`.
- **Solution Code**:

```python
import torch


def hvp(loss, x, vector):
    (grad,) = torch.autograd.grad(loss(x), x, create_graph=True)
    (product,) = torch.autograd.grad(grad, x, grad_outputs=vector)
    return product
```

## Exercise 03.6: Sliding-window dataset

- **Description**: Expose fixed-length history windows and their immediately following target. Reject zero width and out-of-bounds indices.
- **Objective**: Implement `Windows(torch.utils.data.Dataset)`.
- **Solution Code**:

```python
import torch


class Windows(torch.utils.data.Dataset):
    def __init__(self, values, width):
        if width < 1:
            raise ValueError("positive width required")
        self.values, self.width = values, width

    def __len__(self):
        return max(0, len(self.values) - self.width)

    def __getitem__(self, index):
        if not 0 <= index < len(self):
            raise IndexError(index)
        end = index + self.width
        return self.values[index:end], self.values[end]
```

## Exercise 03.7: Collate ragged sequences

- **Description**: Right-pad a nonempty list of 1D CPU token tensors. Return a boolean validity mask independent of the padding token value.
- **Objective**: Implement `collate(rows, pad=0)`.
- **Solution Code**:

```python
import torch


def collate(rows, pad=0):
    data = torch.nn.utils.rnn.pad_sequence(rows, batch_first=True, padding_value=pad)
    lengths = torch.tensor([len(row) for row in rows])
    return data, torch.arange(data.shape[1])[None, :] < lengths[:, None]
```

## Exercise 03.8: Global gradient clipping

- **Description**: Clip model gradients in place and return the original norm. Reject nonfinite gradients and nonpositive limits.
- **Objective**: Implement `clip(parameters, limit)`.
- **Solution Code**:

```python
import torch


def clip(parameters, limit):
    if limit <= 0:
        raise ValueError("positive limit required")
    return torch.nn.utils.clip_grad_norm_(parameters, limit, error_if_nonfinite=True)
```

## Exercise 03.9: Accumulate uneven microbatches

- **Description**: Update once using sample-mean loss across nonempty, possibly unequal microbatches. The supplied loss returns a per-batch mean.
- **Objective**: Implement `microstep(model, optimizer, batches, loss_fn)`.
- **Solution Code**:

```python
def microstep(model, optimizer, batches, loss_fn):
    total = sum(len(y) for _, y in batches)
    if not total:
        raise ValueError("empty training step")
    optimizer.zero_grad(set_to_none=True)
    for x, y in batches:
        if len(y):
            (loss_fn(model(x), y) * len(y) / total).backward()
    optimizer.step()
```

## Exercise 03.10: Custom autograd primitive

- **Description**: Implement a forward and backward pass for the elementwise cube. Support double precision for gradcheck.
- **Objective**: Implement `Cube(torch.autograd.Function)`.
- **Solution Code**:

```python
import torch


class Cube(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x):
        ctx.save_for_backward(x)
        return x.pow(3)

    @staticmethod
    def backward(ctx, upstream):
        (x,) = ctx.saved_tensors
        return upstream * 3 * x.square()
```
